# Akhil Thomas — Video Editor Portfolio

A minimal, high-performance video editing portfolio built with **Next.js**, **Tailwind CSS**, and **Sanity CMS**.

## Stack

- **Frontend:** Next.js (App Router), React, Tailwind CSS
- **CMS:** Sanity Studio (embedded at `/studio`)
- **Hosting:** Vercel

## Features

- **Categorized Reel Grid:** Vertical layout structured by project category.
- **Instant Video Posters:** Automatic first-frame thumbnail generation using browser video metadata.
- **Sanity Studio Integration:** Simple content updates and drag-and-drop video reordering via `@sanity/orderable-document-list`.
- **Responsive Layout:** Optimized for mobile and desktop screens.
